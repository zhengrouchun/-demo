# Proposal

## Why

用户需要用当前 Windows 电脑的麦克风在现实课堂持续把老师讲话转为文字，并免费获得可核对的 Markdown 逐字稿。现有专用课堂页面固定采集系统声音，后端也拒绝 Fun-ASR-Nano 与麦克风组合；原 GrowMate 虽有 Whisper 麦克风入口，但不能据此认定新的课堂入口已经可用或准确率达标。

## What Changes

- 在现有专用课堂入口提供“网课系统声音”和“现实课堂麦克风”两个场景，默认保留系统声音；麦克风场景支持 Windows 默认或指定输入设备。
- 复用现有本地音频采集、独立识别进程、课程开始／暂停／继续／结束、文字自动保存、历史与 Markdown 导出。允许经验证的本地引擎接收麦克风输入，活动课程中锁定来源和设备。
- 新增课前短时麦克风检测、运行中输入音量与采音异常提示，帮助区分“没有声音”“声音太小”“处理积压”和“采集已中断”。失败不得显示为完整成功，也不得静默切换到其他声音来源。
- 将“正确”落实为独立的真实课堂样本评测与 60 分钟麦克风实机验收；现有系统声音成绩不得作为麦克风成绩。优先评测现有 Fun-ASR-Nano GGUF Q8_0，以 Whisper Small 为对照；不满足门槛时报告实测结果并讨论，不宣称准确率已保证。
- 模型准备完成后离线运行，不需要 API Key、订阅或按量付费，不上传课堂声音和文字；不保存整堂课原始录音。
- 补充操作、测试与本次关键语句的作用说明，并明确旧“仅系统声音”范围被本次麦克风扩展。

不包含手机录音导入、混音场景扩展、云端识别、总结、翻译、说话人识别、新推理框架、驱动开发或系统声音长时故障修复。

## Capabilities

### New Capabilities

- `live-classroom-transcription`: 现实课堂麦克风持续采音、本地免费转写、输入检查与故障可见性、逐字稿保存恢复，以及麦克风场景的准确率和长时验收。

### Modified Capabilities

无。`openspec list --specs` 当前返回无主规格；本次通过新增能力描述行为，不把已存在的实现误报为已有规格。

## Impact

- 前端：`LocalLecture/app/frontend/src/growmate/Voice.tsx`、`GrowMateApp.tsx`、`types.ts` 和 `src/main.tsx`；按需要新增小型麦克风检测组件，保持原 GrowMate 和系统声音入口兼容。
- 后端：`meetingbro/growmate/voice.py` 的来源校验与状态、`voice_worker.py` 的引擎／来源组合，及 `web.py` 的本地麦克风检测接口；复用 `audio/capture.py` 与设备枚举，必要的输入检查单独模块化。
- 评测与测试：扩展 `scripts/score_classroom_transcription.py` 支持独立麦克风评分，覆盖现有后端测试、前端构建和课堂页面操作；样本、模型及运行数据不提交 Git。
- 数据：复用 SQLite 与逐字稿目录，不迁移或重标旧历史模型。新增诊断字段保持兼容。
- 依赖：沿用 Python、React/TypeScript、sounddevice 和已接入的本地识别引擎，预计无需新增生产依赖；不需要 `.c/.h`、CubeMX 或自写硬件驱动。
- 已知基线风险：旧系统声音 60 分钟验收未通过，本次不能把麦克风验收结果当作它的修复或通过证据。
