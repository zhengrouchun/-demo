- [ ] 5.1 使用用户提供或另行确认的合计至少 10 分钟真实课堂麦克风音频及人工逐字稿，记录距离、噪声、采样率、时长和课程术语；按统一设置运行现有 Whisper Small 基线及 FunASR，保存不进 Git 的 mic-only 样本清单、识别稿与评分 JSON，人工逐句核对漏句和术语，四项质量门槛全部满足后才标通过。
- [ ] 5.2 新增或扩展只保存指标的实机验证脚本 `scripts/verify_classroom_microphone.py`，支持设备、运行时长和指标输出，复用正式控制器；完成短时真实采音验证，记录实际打开设备、模型、就绪时间、段数、积压、丢块、溢出和资源释放，禁止为长课测试保存整课录音。
- [ ] 5.3 在模型与依赖已准备、无 API Key 且实际断网时运行麦克风课程，验证开始、暂停、继续、尾段排空、UTF-8 Markdown 与临时音频清理；记录断网方式与真实结果，缺模型时验证明确失败且不联网下载。
- [ ] 5.4 在目标电脑真实麦克风上持续运行 60 分钟，输入具有代表性授课语音负载，不能以纯静音代替；正常结束后 10 分钟内导出，记录采集时长、零丢块／溢出、积压峰值、结束耗时和进程退出；任何条件失败均保留失败证据并保持此项未完成。
- [ ] 5.5 转写十分钟后强退再启动，验证已落库文字可恢复且尾段缺失提示明确；另测静音、设备禁用和采集中断，检查有提示、不切设备、不误报完整成功，并核对本应用遗留短窗被清理及其他文件未改动。

以下均为后续实现阶段的命令，本提案未运行产品测试。PowerShell 工作目录为 `D:\语音转文字工具\LocalLecture`；新增测试文件须先由对应任务创建。

```powershell
& .\app\backend\.venv\Scripts\python.exe -m pytest tests/test_growmate.py tests/test_funasr_cli_adapter.py tests/test_score_classroom_transcription.py tests/test_microphone_health.py tests/test_microphone_check.py -q
```

## Workflow follow-up

- 用户确认每个小功能后，按工作区要求提交；提交前复查测试、差异和敏感内容，排除用户未跟踪文件与媒体。
- 提交后核实当前分支、origin 地址及待推送范围，仅向当前非 main/master 分支推送；不得 force。当前已有一个未推送提交，推送会同时包含它，须在用户确认存档范围时说明。
- 最终汇报实际 Commit ID、分支、远程、Push 真实结果与按提交撤销的方法；未提交则明确写未提交，不擅自生成存档。
- 实现及全部验收完成后，只有收到用户明确归档请求才执行 OpenSpec archive；规划完成不等于实施完成。
