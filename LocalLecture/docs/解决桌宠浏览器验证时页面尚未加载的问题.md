# 解决桌宠浏览器验证时页面尚未加载的问题

日期：2026-10-02。

首次运行桌宠浏览器验证时，CDP 导航之后立刻求值 `document.body.innerText`，报 `Cannot read properties of null`。原因是导航指令返回时，新页面尚未创建 body；这是验证脚本的加载等待竞争，不是 GrowMate 页面或桌宠自身的错误。

阅读 `scripts/verify_desktop_pet_browser.py` 的 Page.navigate、evaluate 与 wait，核对现有 `scripts/verify_growmate_browser.py` 的浏览器等待方式，以及 `src/main.tsx` 的 React 挂载入口。

把首次等待条件改为 `document.body?.innerText.includes(...)`，等待正文和人物元素出现，再检查图片 naturalWidth。重跑使用：

```powershell
.\app\backend\.venv\Scripts\python.exe scripts/verify_desktop_pet_browser.py
```

后续鼠标、双击、拖动、刷新位置、睡眠唤醒、隐藏召回和触摸测试通过，没有捕获到前端异常。测试使用自己的临时数据库、Chrome 配置与 5173 端口，不改用户记录，也不打开麦克风。没有安装额外测试框架。
