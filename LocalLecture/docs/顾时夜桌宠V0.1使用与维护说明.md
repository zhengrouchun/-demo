# 顾时夜 Q 版桌宠 V0.1 使用与维护说明

更新日期：2026-10-03。本次在现有 GrowMate 网页增加独立悬浮小人，不建立新项目。角色为本次生成的黑发、灰蓝眼、黑色长外套 Q 版，PNG 透明背景。

## 先看如何使用

启动 GrowMate 后刷新 `http://127.0.0.1:8876/`，小人默认在右下角，所有 GrowMate 页面都能看见。

- 点人物：短句回应和动作；快速点两次有惊讶回应，连续多次更容易出现“别闹”。
- 按住人物拖动：松开保存位置，刷新仍保留。手机使用触摸拖动。键盘聚焦人物后，方向键也能移动。
- 点人物脚下的 **⋯**：调整大小，开关随机动作、气泡和自动睡眠；可请求鼓励、陪伴或招手，也能重置位置。
- 点 **−** 或“暂时隐藏”：人物收起，右下角留下“顾”按钮，点击召回。隐藏状态也会保存。
- 无操作五分钟会睡觉；移动鼠标、点页面、键盘或滚动会唤醒。眨眼、招手随机出现，不主动不停聊天。

桌宠是网页内浮层，跟随当前浏览器页面；不会出现在其他软件或 Windows 桌面上。它使用本地配置台词，不需要联网或 API Key，也不读取电脑代码报错或推断真实情绪。原 AI 陪伴页面的联网功能照原设置使用。

## 1. 项目原来的技术栈

现有网页使用 React 18、TypeScript、Vite 与普通 CSS，后端为 FastAPI。本次沿用它们，未安装新 npm 包、未升级依赖、未修改 package.json。

采用 React Portal 把悬浮层挂到 `document.body`，避免被普通卡片或页面滚动裁切；桌宠样式全部限制在自己的类名内。层级为 30—32，低于现有 Toast 和重要遮罩，手机默认给底部导航留空间。

## 2. 新增文件及作用

模块目录：`app/frontend/src/components/DesktopPet/`。

- `DesktopPet.tsx`：人物显示、鼠标/触摸 Pointer Events、拖动边界、窗口缩放、隐藏召回和清理。把移动坐标放在 ref 中，拖动用 requestAnimationFrame 更新 transform，松开才提交位置。
- `PetBubble.tsx`：单一对白气泡，测量尺寸并约束到窗口内，支持上方/下方和淡入淡出。
- `PetMenu.tsx`：小型设置面板、尺寸与行为开关、鼓励和招手入口。
- `petState.ts`：状态类型和动作优先级。预留 WALK、WORK、HAPPY、ANGRY、AI_CHAT。
- `petConfig.ts`：尺寸、素材路径、时间段、动作时长、概率、睡眠、点击阈值和扩展配置。
- `petDialogues.ts`：所有角色台词按类别集中保存，问候也在这里。
- `dialogueEngine.ts`：结合时间、连续点击、离开时长、近期对白和冷却选择台词，不放在事件处理器内。
- `petStorage.ts`：统一设置保存、容错读取、位置限制、会话问候去重。
- `petActions.ts`：纯 TypeScript 控制器，一个调度器管理动作、气泡、点击与睡眠，不依赖页面业务。
- `petAssets.ts`：异步预加载核心图片，动作缺图退回 idle，idle 也不可用时显示小“顾”占位，避免整个页面报错。
- `styles.css`：透明悬浮、人物反馈动画、设置/气泡外观、移动端与减少动画偏好。

图片目录：`app/frontend/public/pet/gushiye/`，保存 `idle.png`、`blink.png`、`touch.png`、`wave.png`、`surprise.png`、`drag.png`、`sleep.png`。素材说明与生成提示词保存在同目录的 `README.md`。

另新增 `scripts/verify_desktop_pet.cjs`、`scripts/verify_desktop_pet_browser.py` 和 `scripts/verify_desktop_pet_assets.py`，分别验证核心规则、真实浏览器交互和 PNG 透明通道；不操作你的正式数据库、录音设备或浏览器账户。

## 4. 桌宠执行流程

页面加载 → 渲染既有 GrowMate → 读取 `desktopPet.settings` → 校验配置/位置 → 约束到当前窗口 → 异步加载 PNG → 显示 IDLE → 启动事件与统一调度器。

没有保存位置时放右下角。每次拖动结束、缩放或窗口改变会保存合理坐标。localStorage 被禁用、格式错误或坐标越界时仍可使用本页，不因此崩溃。保存内容只有桌宠设置、位置与对白冷却时间，不含业务数据或 API Key。

问候在首次有效显示后按本地时间选择，用 sessionStorage 的当天标记与内存容错避免刷新或 React StrictMode 重复问候；一天在当前浏览会话最多主动一次。

## 5. 点击流程

pointerdown → 记录起点并捕获指针 → pointermove 检查移动距离 → pointerup → 判断点击或拖动 → 等待 280ms 区分单击/双击 → 更新短时 clickCount → selectDialogue → 选择 TOUCH/WAVE/SURPRISE → 替换单一气泡 → 动作到期恢复 IDLE。

移动距离至少 5px 才进入 DRAG，拖过以后不会再触发点击。pointercancel 或丢失捕获会安全结束拖动，不制造一次点击。连续点击在 6 秒无新点击后归零；第 3 次起提高“别闹”权重，第 5 次起可出现惊讶。

## 6. 状态机

- **IDLE**：初始化、动作完成、拖动结束或唤醒后进入；等待随机事件、点击或睡眠。
- **BLINK**：IDLE 随机触发，200ms 后恢复。
- **WAVE**：随机招手、点击或设置里的招呼触发，约 1400ms 后恢复。
- **TOUCH**：单击的常见回应，约 1100ms 后恢复。
- **SURPRISE**：双击或频繁点击回应，约 1100ms 后恢复；不放入常规随机池。
- **DRAG**：超过移动阈值后进入，优先级最高；松开或取消后恢复，期间不被随机动作打断。
- **SLEEP**：IDLE 且长时间无操作进入，关闭随机动作；用户重新活动后唤醒，唤醒本身不不停弹气泡。
- **WALK**：V0.2 类型、图片帧与配置接口已预留，V0.1 不实际执行走路。WORK/AI_CHAT 等也不伪造环境判断。

拖动优先于 TOUCH/SURPRISE，后者优先于 WAVE、BLINK、IDLE。只有一个动作截止时间。隐藏/卸载清理调度器、监听、指针捕获和 requestAnimationFrame；不会因为刷新或多次召回叠加几十个定时器。

## 7. 如何替换图片

把透明 PNG 放进：

```text
D:\语音转文字工具\LocalLecture\app\frontend\public\pet\gushiye\
```

同名替换即可；改文件名时更新 `petConfig.ts` 的 `PET_ASSETS`。建议所有 PNG 使用相同画布、角色中心和脚底位置，避免切换动作时跳动；不要把白底图当透明图。缺少动作 PNG 自动使用 idle。

修改 public 目录后重新双击启动文件，脚本会按需构建；已运行时也可在 `app/frontend` 执行 `npm.cmd run build`，再刷新浏览器。只替换源码目录中的图片不会自动改变已经构建的 dist 副本。

## 8. 如何增加台词

编辑 `petDialogues.ts` 的 `PET_DIALOGUES`。例如把“早点睡。”加进 `lateNight` 数组；普通短句放 `minimal`，学习鼓励放 `coding`，特殊事件放 `project`。时间问候放 `GREETINGS` 的对应时段。

最近四句会避免重复，台词全部通过普通文本渲染，不执行 HTML。请保留极简池的多个候选，便于去重；代码/焦虑/重要事件只是配置台词池，不能据此声称检测到了真实状况。

## 9. 如何调整概率

编辑 `petConfig.ts` 的 `PET_CONFIG.dialogue.weights`：默认 minimal 50、coding 25、care 15、direct 10。它们是基础相对权重，上下文与冷却会改变最终比例。

其他调节项同样在配置里：`repeatedMinimalBoost`、`repeatedLineWeight`、`longIdleBoost`、`contextBoost`、`careDailyChance` 和 `encouragementWeights`。鼓励类别下有少量焦虑/项目台词；身体提醒不是每次点击固定出现。

直球冷却由 `directCooldown: 600000` 控制，默认十分钟，时间戳同设置保存，刷新不立即绕过冷却。连续戳人物时暂停选择直球，避免连续出现。

## 10. 如何调整随机动作频率

编辑 `PET_CONFIG.randomAction.minDelay` 与 `maxDelay`，默认 8000—25000 毫秒；`blinkWeight: 0.75` 表示眨眼约占 75%，其余为招手。动作持续时间在 `PET_CONFIG.action`。也可直接在桌宠设置里关闭随机动作。

## 11. 如何调整睡眠时间

编辑 `PET_CONFIG.sleep.timeout`，默认 `300000` 毫秒，即五分钟。开关由桌宠设置里的“久未操作时睡觉”控制，保存为 `autoSleep`。普通鼠标移动只更新时间戳，只有需要唤醒时触发状态更新。

## 12. 如何关闭 WALK

当前 V0.1 不执行 WALK，默认 `PET_CONFIG.walk.enabled` 为 false，保存设置的 `walkEnabled` 也默认 false。未来实现走路时，按既有状态和 `WALK_FRAMES` 接口接入；不要仅把布尔值改 true 就当作已实现横向行走。
