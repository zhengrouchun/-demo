GrowMate V0.1 产品需求文档产品代号：GrowMate第一目标平台：Android后续平台：iOS、Windows使用对象：个人使用当前阶段：V0.1 MVP核心体验：专注 → 获得水滴 → 手动浇树 → 树成长 → 开花结果 → 永久进入森林 → 种下一棵树1. 产品定位GrowMate 是一个融合：自律专注番茄钟虚拟种树森林养成每日提醒Markdown 备忘录图片记录养胃记录心情日记AI 陪伴的个人成长 App。整个 App 不应该给用户一种“工具集合”的感觉，而应该围绕：小狗陪着用户照顾一片森林。所有功能尽量与这个主题连接。例如：专注时：小狗趴在树下学习。专注完成：小狗拿到水壶。浇水时：小狗给树浇水。树缺水：小狗守在树旁。AI 聊天：小狗陪用户聊天。提醒吃饭：小狗举起吃饭提醒牌。心情记录：小狗询问“今天过得怎么样？”树成熟：小狗和用户一起庆祝。2. 技术路线2.1 第一版采用：React Native+Expo+TypeScript+Expo SQLite+Expo Notifications+Expo SecureStore+免费 AI API原因是第一版需要 Android 真机体验，同时未来还希望支持 iOS，因此 React Native 比继续使用 Electron 更合适。当前 MeetingBro 是 Electron + React + TypeScript 的桌面前端，而不是 Android 工程。因此采用：MeetingBro    ↓保留架构经验和可复用业务思想    ↓新建 React Native / Expo App而不是尝试让 Electron APK 化。3. MeetingBro 可以复用什么可以复用1. TypeScript 数据模型思想继续使用 TypeScript 定义：FocusSessionTreeNoteMoodLogAIMessage等数据模型。2. AI 接入思想MeetingBro 当前已经存在 OpenAI Compatible Client，并且已经有模型 API 配置思想。因此 GrowMate 的 AI 层继续设计成：AIProvider    ↓OpenAI-compatible API以后可以更换：GroqOpenAIOpenRouter自建模型服务而不修改 AI 页面。3. SQLite 思路MeetingBro 已经使用 SQLite 保存结构化数据，并采用“创建表 → Storage 层 → CRUD”的架构。GrowMate 继续采用 SQLite，但 Android 端改用：expo-sqliteExpo SQLite 的数据库能够在 App 重启以后继续保存。4. 第一版底部导航采用 5 个一级入口：🏠 首页⏱ 专注🌲 森林📝 记录🐶 陪伴5. 首页首页负责让用户一打开 App 就知道：当前树怎么样。今天专注了多久。有多少水。今天有没有完成记录。接下来应该做什么。页面结构：┌──────────────────────┐│ 早上好               ││                 🔔   ││                      ││ -1同时触发掉叶动画第一次：❤️❤️🖤第二次：❤️🖤🖤第三次：🖤🖤🖤树彻底枯萎。状态：dead之后不能继续浇水。用户需要：重新选择种子14. 一天没有浇水开始掉生命这是正式规则：最后浇水日期     ↓超过一个完整自然日没有浇水     ↓HP -1例如：9月27日浇水9月28日整天没有浇水进入9月29日检查时：HP -1为了避免用户一天打开 App 多次连续扣血，数据库必须记录：last_health_penalty_date算法：当前日期-last_watered_date计算未浇水天数。再比较：last_health_penalty_date只对新的缺水日扣一次。不能简单写成：if 今天没浇水:    HP--否则用户每打开一次 App 都可能掉一次生命。15. AI 健康功能定位AI 可以：提供一般食品信息。分析用户自己输入的饮食记录。给日常饮食习惯建议。提醒规律饮食、合理作息。结合用户选择发送的记录回答问题。AI 不负责：诊断疾病。判断用户患有什么病。替代医生。擅自推荐处方药。涉及持续明显不适、出血、严重疼痛等情况时，应该建议寻求专业医疗帮助。26.
